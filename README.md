# CS-210-Portfolio
SNHU CS 210 Programming Languages portfolio featuring my Corner Grocer C++ project.

For my CS 210 portfolio, I selected my Corner Grocer project. The purpose of this project was to develop a C++ program that could analyze grocery purchase data and identify how frequently different items were purchased. The program allows users to search for individual items, view a list of purchase frequencies, and display the results as a histogram. It also creates a backup file to store the frequency information. I appreciated that this project had a practical business application because I could understand how the information might help a grocery store make inventory decisions.
I think one of the things I did particularly well was creating a program that was functional and relatively easy to navigate. I tested the different menu options to make sure they produced the expected results. More importantly, I think I did well with troubleshooting. There were several moments throughout this course when I struggled to understand why my code wasn't working, but I continued reviewing errors, making corrections, and testing until I achieved the expected results.
One area where I could improve my code is input validation and error handling. While the program works with the expected inputs, I would like to make it more reliable when unexpected information is entered or when a file cannot be accessed. I also want to become better at recognizing opportunities to simplify my code and make it more efficient. At this stage, I am still learning how to build programs correctly, and I know that writing clean, efficient code will come with additional practice.
One of the most challenging parts of this project was understanding how the different components worked together, particularly classes, functions, and file input and output. I often found that I could understand code when reading it but struggled to write it independently. To overcome these challenges, I broke assignments into smaller steps, reviewed course materials, practiced with examples, and used AI assistance to help explain concepts and troubleshoot errors. These resources helped me work through problems, although I recognize that I still need more independent practice.
The skills I developed throughout this project will be useful in future coursework and my career. My professional experience is primarily in business operations, and one of my long-term goals is to help bridge the gap between business needs and technology. This project helped me understand how programming can transform raw data into information that supports business decisions. I also strengthened my problem-solving, debugging, and organizational skills.
To make my program maintainable, readable, and adaptable, I organized the code using object-oriented programming principles and separated responsibilities into different functions. I also used descriptive names and comments to make the code easier to understand. This structure allows individual parts of the program to be modified without having to rewrite everything. As I continue learning, I want to improve my ability to write programs that are not only functional but also easy for other developers to understand and maintain.
Final Reflection
If I am being completely honest, this course has been a combination of learning C++ and learning how to successfully complete C++ assignments. There were times when I genuinely understood the concepts and could recognize what the code was supposed to accomplish. Other times, I was simply trying to figure out why something wasn't working and how to get it submitted correctly.
One of my biggest challenges has been the difference between reading code and writing it independently. I can often understand the logic when it is presented to me, but starting with a blank screen and building a program from scratch is still intimidating. Between balancing school, working full-time, and raising my children, I also struggled with time management and occasionally fell behind.
I relied on examples, course resources, and AI assistance to help me understand concepts and troubleshoot problems. While these resources helped me complete assignments, I also recognize that I need more independent practice to strengthen my programming skills.
Despite the challenges, I have made progress. I understand more about how programs are structured, how functions and classes work together, and how to approach errors without immediately feeling defeated. I am not leaving this course as a confident C++ programmer, but I am leaving with a stronger foundation than I had when I started.
Ultimately, this course reminded me that learning something new isn't always a smooth process. Sometimes progress looks like understanding a concept, and sometimes it looks like spending an hour figuring out one error. Both have been part of my experience, and I am proud that I kept going.
